Hashcat
Password Audit Lab

Étude pratique du cassage d’empreintes de mots de passe avec Hashcat 8.0.0 : dictionnaire, règles de mutation et attaque hybride. Tous les tests présentés ont été réalisés sur des empreintes et mots de passe synthétiques dans un environnement local de laboratoire.

02 / Environnement de test

Software

Hashcat 8.0.0

Exécuté depuis PowerShell sur Windows. Les commandes utilisent des chemins locaux vers l’exécutable et les fichiers de laboratoire.

Hardware

NVIDIA GeForce RTX 4060 Laptop GPU

Hashcat a utilisé OpenCL. L’initialisation de la bibliothèque NVIDIA RTC/CUDA n’était pas disponible ; le repli OpenCL a fonctionné pour ces exercices.

Scope

Données synthétiques

Aucune empreinte réelle ni aucun compte tiers n’a été ciblé. Les tests sont reproductibles sur des données créées pour le lab.

03 / Exercices réalisés

Attaque par dictionnaire — MD5

Mode -m 0, attaque dictionnaire -a 0. La wordlist contenait six candidats synthétiques.

POWERSHELL · EXERCISE 01
hashcat.exe -m 0 -a 0 hashes.txt wordlist.txt --potfile-path exercise-01.pot

Résultat observé : Cracked · 3/3 · progression 6/6 · environ 3 167 H/s.

Attaque par dictionnaire — SHA-256

Mode -m 1400 pour SHA-256, en conservant la méthode par dictionnaire.

POWERSHELL · EXERCISE 02
hashcat.exe -m 1400 -a 0 sha256-hashes.txt wordlist.txt --potfile-path exercise-02.pot

Résultat observé : Cracked · 3/3 · progression 6/6 · environ 10 603 H/s.

Échantillon trop petit pour conclure que SHA-256 est généralement plus rapide que MD5 ; les conditions de mesure sont limitées à ce test.

Attaque par règles — best66.rule

Application de mutations aux mots du dictionnaire. Le fichier best64.rule n’était pas présent dans cette installation ; le fichier best66.rule disponible a été utilisé.

POWERSHELL · RULE-BASED
hashcat.exe -m 0 -a 0 hashes.txt wordlist.txt -r rules\best66.rule --potfile-path exercise-01-rules.pot

Résultat observé : Cracked · 3/3 · 396/396 candidats · environ 434,4 kH/s.

Attaque hybride — dictionnaire + trois chiffres

Le masque ?d?d?d ajoute trois chiffres à chaque entrée du dictionnaire.

POWERSHELL · HYBRID ATTACK
hashcat.exe -m 0 -a 6 hash.txt wordlist.txt '?d?d?d' --potfile-path hybrid.pot

Le premier essai sur les trois mots de passe initiaux a terminé en Exhausted, avec 0/3 résultat : aucun ne correspondait au masque testé. Après création d’une empreinte synthétique pour welcome123 et d’une wordlist contenant welcome, le test a réussi.

Résultat de validation : Cracked · 1/1 · 1 000/1 000 candidats · environ 399 kH/s.

05 / Compétences démontrées

Comprendre les modes

Choisir le mode correspondant au type d’empreinte et distinguer dictionnaire, règles et attaque hybride.

Lire les résultats

Interpréter Cracked, Exhausted, la progression, le nombre de candidats et les performances affichées.

Documenter proprement

Conserver un potfile séparé par exercice, isoler les jeux de test et expliciter les limites des mesures.

Cadre éthique : ce laboratoire est destiné à l’apprentissage et à l’audit autorisé. Ne tester que des empreintes que vous possédez ou pour lesquelles vous disposez d’une autorisation explicite. Les mots de passe affichés ici sont des exemples synthétiques, pas des identifiants réels.
