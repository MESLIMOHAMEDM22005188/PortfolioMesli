01 / Core capabilities

A practical toolbox for
everyday document work.

The project brings desktop interactions, API endpoints and database records together, with a focus on making common file operations explicit.

↥

Controlled file imports

Import supported PDF, PNG, JPG, JPEG and DOCX files. The current import flow checks the extension and enforces a 5 MB size limit.

▤

File and folder operations

Browse the library, organize files into folders, move files, and use recorded original paths to support restoration workflows.

⌕

Desktop-first navigation

A PyQt5 interface groups document actions into dedicated windows and controllers instead of mixing all interaction logic in one place.

⇄

API-backed account flows

FastAPI exposes registration and sign-in endpoints, with request validation and password hashing handled in the backend layer.

PDF

PDF certificate generation

Generate a structured certificate document from submitted fields and return it as a downloadable PDF response.

DB

Persistent metadata

SQLAlchemy maps users, files, folders and generated documents to relational records, while allowing local SQLite development or MySQL configuration.

02 / User journey

From import to
organized output.

A simple flow keeps the responsibilities of the desktop UI, backend and storage layer understandable.

Select a document

Choose a local file and apply the supported-format and size checks before importing it.

Register metadata

Copy the file into the configured storage directory and persist its path, type, size and status.

Organize and manage

Use the desktop interface to browse files, move them into folders, or restore recorded locations.

Generate a document

Submit certificate fields to the API and receive a generated PDF as the operation’s output.

04 / Engineering perspective

Built to improve.
Not to overclaim.

The next iterations are about reliability, privacy and trustworthy document workflows—not just adding more buttons.

Engineering focus

Reliability and maintainability

Prioritize predictable behavior when files move or database operations fail, and keep the codebase testable as its features grow.

  • Automated tests for file and folder edge cases
  • Database migrations instead of ad-hoc schema changes
  • Structured logging without secrets or verification codes
Potential next steps

Safer document workflows

Extend the current foundation into a robust workflow for sensitive documents, with explicit security boundaries and traceability.

  • Per-user file authorization and server-side verification
  • Content validation, safer storage paths and audit history
  • Integration with a real e-signature provider if signing is required
Scope note: the current project covers file management, account-flow foundations and PDF generation. This showcase does not claim a legally qualified electronic-signature implementation or production-grade multi-user authorization.
