Project Overview

SecureCloudLab brings together infrastructure as code and a local dashboard to explore cloud-security practices, validate Terraform configuration, scan for common misconfigurations and review findings. CI verifies code and does not automatically provision AWS resources.

01 / INFRASTRUCTURE

AWS network baseline

A configurable VPC with public and private subnets across two Availability Zones, routing controls and separate network ACLs.

02 / AUDIT & MONITORING

Logs and security signals

Terraform definitions for VPC Flow Logs, CloudTrail, a protected S3 audit bucket, AWS Config rules and GuardDuty alert routing.

03 / SECURITY SCANNING

IaC validation

A local FastAPI dashboard integrates supported Terraform and Checkov operations to display scan output and security findings.

04 / REPORTING

Findings and scan history

Dashboard pages cover security analysis, infrastructure checks, network topology, settings and saved scan reports.

05 / AUTOMATION

CI security checks

GitHub Actions workflows cover Terraform formatting and validation, tests, TFLint, Checkov and Gitleaks secret scanning.

06 / SAFE DEPLOYMENT

Review before applying

The CI workflow does not run Terraform apply or destroy. Infrastructure changes require explicit review and authorised deployment.

Project scope: This is a learning and portfolio project, not a production-ready AWS landing zone. Automated checks help identify risks but cannot guarantee that an environment is secure. Review AWS costs and configuration before deploying resources.
