Hashcat Password Auditing Lab

An advanced, isolated exercise to compare dictionary-based recovery against synthetic MD5 and SHA-256 hashes, document device constraints, and explain secure password-storage choices.

Lab guide prepared · execution evidence pending

Objectives

01 / Reproducibility

Generate a deterministic set of fictional hashes and a small known wordlist.

02 / Audit

Run Hashcat in a Docker container against test data only.

03 / Compare

Compare recovered counts and measured runtime while recording device information.

04 / Defend

Explain why fast general-purpose hashes are unsuitable for password storage.

Architecture

Host machine
  ├── Python fixture generator
  ├── labs/hashcat/lab/  (synthetic hashes + wordlist)
  └── Docker Compose
       └── hashcat/hashcat container
            └── reads and writes only the mounted lab directory

No network target is involved. GPU access depends on host drivers and container runtime configuration; device support must be verified rather than assumed.

Workflow

From the labs/hashcat/ directory in the repository:

python scripts/generate_fixtures.py
docker compose run --rm hashcat --version
docker compose run --rm hashcat -I

# MD5 dictionary audit
docker compose run --rm hashcat -m 0 -a 0 /lab/hashes-md5.txt /lab/wordlist.txt --potfile-path /lab/md5.pot --outfile /lab/md5-recovered.txt

# SHA-256 dictionary audit
docker compose run --rm hashcat -m 1400 -a 0 /lab/hashes-sha256.txt /lab/wordlist.txt --potfile-path /lab/sha256.pot --outfile /lab/sha256-recovered.txt

Run commands locally and retain the actual output. The portfolio page does not claim that these commands have already been executed.

Security findings

Fast hashes

MD5 and SHA-256 are designed for general-purpose hashing and are fast to calculate, which makes large-scale password guessing easier.

Recommended storage

Use password-specific schemes such as Argon2id, scrypt, or bcrypt with unique salts and parameters appropriate to the application.

Scope limitations

A tiny wordlist experiment is educational, not a general benchmark and not proof that every password is recoverable.

Reproducibility and ethics

This exercise is restricted to synthetic data generated by the included script. Do not substitute hashes from real users, leaked datasets, or systems without explicit authorization. The results table remains pending until measurements are captured.
