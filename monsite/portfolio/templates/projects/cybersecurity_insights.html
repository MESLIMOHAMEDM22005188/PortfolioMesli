🚨 Cybertrace

Reste informé des vulnérabilités critiques publiées par le CERT-FR grâce à un agrégateur codé 100% en Rust.

Voir les fonctionnalités

Fonctionnalités clés

Développement en Rust

Le backend repose entièrement sur le framework web léger Axum, avec une architecture simple et rapide à déployer.

Scraping RSS

Un parser intelligent récupère les flux RSS du CERT-FR, extrait les informations utiles et les transforme en JSON.

Interface épurée

Une UI inspirée d’Apple : sombre, minimaliste, lisible, pour visualiser les failles critiques en un clin d’œil.

Pourquoi ce projet ?

J’ai conçu Cybertrace pour m’initier à Rust de manière concrète, tout en me familiarisant avec les problématiques de scraping, de parsing XML/RSS, et de conception d’API REST. Le projet m’a aussi permis de pratiquer l’intégration front avec Tailwind.
