What is this website?

This website is more than a CV. It is a web application built to centralize and present my technical progression through projects, experiments, certifications and professional experiences.

Project Showcase

Each project has its own dedicated presentation page containing its purpose, technologies, features and links to the source code when available.

Technical Profile

The portfolio brings together my programming languages, development tools, databases, deployment technologies, cybersecurity tools and algorithms.

Professional Journey

A dedicated timeline presents my education, internships, technical missions and professional experiences.

Technology Stack

Built with Django

Backend

The website is developed with Django, using Django templates and named URL routes to organize the different portfolio pages and project views.

Frontend

The interface combines HTML, CSS and JavaScript with Tailwind CSS on several project presentation pages to create responsive and interactive layouts.

Dynamic Content

Django templates are used to generate navigation links, project pages, static resources and reusable elements across the site.

Deployment

The website is deployed online using Render, making the portfolio publicly accessible through a production deployment.
