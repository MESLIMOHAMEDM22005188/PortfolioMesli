Under the hood

From rules to decisions.

The project is organized around the game state, the current player, legal moves, and a UI that reflects every turn.

Core components

  • ✓Game model — represents the pile state, applies moves, and detects the end of a match.
  • ✓Player strategies — share a common interface for human and bot-controlled turns.
  • ✓Learning bot wrapper — tracks episodes and logs move context for future experiments.
  • ✓Tkinter interface — connects the visual board to game state and player actions.

Learning journey

What this project makes possible.

Nim is a useful sandbox: its rules are small enough to understand, but its strategy creates meaningful opportunities for experimentation.

01 / Game logic

Understand state and legal actions

Model a match, prevent invalid moves, and define a precise end condition.

02 / Strategy

Compare decision-making approaches

Observe how a random opponent differs from strategies designed to improve play.

03 / Experiments

Collect data from matches

Use episode logs as a foundation for analyzing moves and testing future changes.

04 / Next iteration

Build a stronger learning loop

Extend the prototype with explicit rewards, policy updates, evaluation runs, and win-rate tracking.
